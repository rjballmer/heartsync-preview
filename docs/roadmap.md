# Roadmap

## Public sample v1

- Core breathing timing model
- Heartbeat-style haptic pattern specification
- Session lifecycle state machine
- Privacy guardrail model
- Unit tests and CI

## Candidate public additions

- Minimal SwiftUI sample shell
- Device-safe haptic demo using Core Haptics
- Accessibility settings for visual-only mode
- Local session summary model without health claims

## Private / not yet public

- live physiological feedback
- camera or Watch sensing loop
- coherence visualization
- adaptive haptic algorithms
- invention-sensitive implementation details

The intent is to show the foundation without publishing the strongest closed-loop product ideas prematurely.
